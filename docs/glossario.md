# Glossário PT-BR ↔ identificadores de código

Domínio do diagrama de classes (`docs/diagramas/04`). Código em inglês; interface e documentação em português.

| Português (documento/UI) | Código |
|---|---|
| Usuário | `User` |
| Locatário / Anunciante (tipos de conta) | `AccountType`: `TENANT` / `LISTER` |
| Anúncio | `Listing` |
| Condições contratuais (prazo mínimo, multa, taxas) | `ContractTerms` (`minTermMonths`, `earlyExitFee`, `monthlyFees`) |
| Perfil de convivência | `LivingProfile` |
| Interesse de match | `MatchInterest` (`isMutual` derivado) |
| Conversa / Mensagem | `Conversation` / `Message` |
| Confirmação de locação | `LeaseConfirmation` |
| Avaliação | `Review` |
| Imóveis salvos | `SavedListing` |
| Comparativo de valores | `PriceComparison` (`BELOW`/`WITHIN`/`ABOVE`) |
