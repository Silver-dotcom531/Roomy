# Documentação

Documento de especificação do Projeto Integrador do Roomy, atualizado a cada fase, e diagramas de modelagem do sistema.

- `diagramas/01-casos-de-uso.png`: atores e casos de uso do sistema
- `diagramas/02-fluxo-locacao.png`: fluxo de locação, da publicação do anúncio à avaliação mútua
- `diagramas/03-fluxo-match.png`: fluxo de compatibilidade entre locatários
- `diagramas/04-classes-conceituais.png`: classes conceituais do domínio
- `diagramas/fonte/`: arquivos-fonte dos diagramas (`.py` gerado com Matplotlib, `.dot` com Graphviz)
